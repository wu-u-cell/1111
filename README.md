# 生活助手

安静的 Windows 个人助手。开始菜单搜索 **生活助手** 打开。

## 功能

- 待办：新增、编辑、完成、恢复、删除，按完成状态筛选。
- DDL：可选截止时间；到点、提前 10 分钟、1 小时或 1 天提醒，每项一次。
- 安静提醒：后台无窗口运行，登录后启动；同批到达的提醒合并为一条无声音 Windows 通知。可暂停全部通知。
- 书单：小说、数据科学、哲学、心理成长、习惯、专注等主题，附推荐理由和作者、出版社或合法阅读链接。
- 国际新闻：联合国新闻中文、BBC World 英文 RSS。首次打开新闻页或点击刷新时获取，显示来源、发布时间和原文链接；支持离线缓存，不发新闻通知。
- 开屏书摘：每次打开或刷新页面随机显示一句内置经典短句，附作者、书名与出处链接；同一浏览环境中避开上一句。只在浏览器本地记录上一句的编号，不涉及个人待办数据。

## 安装与启动

Windows 10/11，Python 3.10+（含 sqlite3 和 pythonw.exe），无需 pip 依赖。界面使用本地网页与 Microsoft Edge 独立应用窗口；未安装 Edge 时使用默认浏览器。服务只监听本机 127.0.0.1，数据接口需要启动时生成的访问令牌。

在项目目录的 PowerShell 中运行 `./install.ps1`。安装程序创建当前用户的开始菜单快捷方式、登录启动快捷方式和通知名称注册项，无需管理员权限。也可直接用 `python app.py` 启动。

安装后在开始菜单搜索“生活助手”，搜索索引可能需要一点时间。项目移动后需重新安装。关闭主窗口不停止 DDL 提醒。

## 时间与提醒

- 时间格式为 `2026-11-01 18:00`，使用电脑本地时区。普通待办可以不设 DDL。
- 提醒程序每 20 秒检查一次，可能有约 20 秒延迟。
- 关机、休眠或未登录时不能提醒；恢复运行后，合并补发未完成且尚未通知的事项。恢复暂停通知也采用相同规则。
- Windows 勿扰模式和系统通知权限可能让通知只进入通知中心；应用不修改系统通知设置。
- 修改待办会重新安排提醒，已完成事项不提醒。通知是文本提示，点击不会直接打开待办。

## 数据与网络

待办、设置、新闻缓存位于 `%LOCALAPPDATA%/LifeAssistant`，不在仓库中，不会上传 GitHub。SQLite 数据文件可在设置中打开目录后备份。代码公开不代表个人数据公开。

仓库采用默认排除规则：仅允许列出的应用源文件、界面文件、图标、文档和测试被常规 Git 操作加入。其他文件（包括误放进项目的资料、导出、数据库、缓存、令牌和配置）默认忽略。应用本身没有 GitHub 上传或云同步功能。不要把个人内容写入源码，也不要用 `git add -f` 强制加入私有文件；Git 的忽略规则无法阻止这些手动操作。更新应用代码不会覆盖仓库外的个人数据库。

书单是人工整理的内置精选，不调用 AI，不收集阅读行为。新闻通过 HTTPS 直接请求所选 RSS，点击链接由默认浏览器打开。网络失败明确提示，旧缓存不会标成新新闻。

来源：[联合国 RSS 说明](https://news.un.org/zh/rss-feeds)、[BBC World RSS](https://feeds.bbci.co.uk/news/world/rss.xml)、[午夜图书馆作者介绍](https://www.matthaig.com/the-midnight-library/)、[Python 数据分析作者在线版](https://wesmckinney.com/book/)、[统计学习导论官网](https://www.statlearning.com/)。其他书目在应用中附有原始来源。

## 验证

运行 `python -m unittest discover -s tests -v`，覆盖数据持久化、提醒去重、失败重试、完成/暂停抑制、编辑重排，以及 RSS 去重、排序、链接过滤。测试不发送真实通知。

## 移除

运行 `./uninstall.ps1` 移除入口和登录启动、停止本项目进程；保留源码与个人数据。只需暂停提醒时，使用应用内“安静设置”。
